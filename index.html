Turn any website into an
Agent Skill

Paste a URL → crawl the site → generate a ready-to-deploy Hermes Agent Skill and/or OpenClaw Agent Package. Fully automated. LLM-powered. Open source.

⭐ Star on GitHub 🚀 Quick Start

⚡ How It Works

# Crawl, analyze, generate — one command python src/website_to_skill.py \ --url https://example.com \ --format hermes+openclaw \ --output ./my-skill

🧠 What You Get

🌐 Smart Crawling

Recursive sitemap + link following. Respects robots.txt, rate limits, and noindex tags. Filters binary files and stays on-domain.

🧪 LLM Analysis

Classifies the site, extracts workflows, maps interaction points, identifies agent use cases. Works with OpenAI, OpenRouter, or any compatible provider.

⚙️ Hermes Skill

Generates SKILL.md with proper frontmatter, reference docs, and raw-page extracts ready for Hermes Agent.

🎯 OpenClaw Package

Generates PACKAGE.md, SOUL.md, IDENTITY.md, AGENTS.md — a deployable agent package.

🔒 Privacy Safe

Runs locally. No data sent to third parties except your configured LLM provider. Your crawls stay yours.

🐍 Zero Setup

Python 3.11+. Install deps, set your API key, run. No Docker, no build step, no infrastructure.

📦 Output Structure

output/
├── SKILL.md                    ← Hermes skill definition
├── site-map.md                 ← Crawled site structure
├── key-actions.md              ← What agents can do
├── interaction-guide.md        ← How to interact
├── identity.md                 ← Agent identity
├── references/
│   ├── raw-pages/            ← Extracted page content
│   └── analysis.json            ← LLM analysis
└── PACKAGE.md                  ← OpenClaw manifest

🔧 Quick Start

# 1. Install deps pip install -r requirements.txt # 2. Configure your API key cp .env.example .env # Edit .env with your OpenAI/OpenRouter key # 3. Run it python src/website_to_skill.py \ --url https://example.com \ --format hermes+openclaw \ --output ./my-skill # Options # --format hermes → Hermes skill only # --format openclaw → OpenClaw package only # --provider openrouter → Custom LLM provider # --model deepseek/deepseek-v4-pro # --max-depth 2 → Crawl depth # --max-pages 50 → Page limit
