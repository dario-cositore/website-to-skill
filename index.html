⚡ What It Does

🕷️ Smart Crawl

Follows sitemaps + links recursively. Respects robots.txt, noindex, and rate limits. Filters binary files automatically.

🔍 Heuristic Analysis

Classifies the site, extracts workflows, maps interaction points, and identifies agent use cases using HTML structure and content patterns. Zero API costs.

⚙️ Hermes Output

Generates SKILL.md with full frontmatter, reference docs, raw-page extracts, and interaction guides.

🎯 OpenClaw Output

Generates PACKAGE.md, SOUL.md, IDENTITY.md, and AGENTS.md — a deployable agent package.
